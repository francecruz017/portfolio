# Adan France Cruz — Portfolio

Personal portfolio built with React, TypeScript, Vite, and Framer Motion.

## Local development

```bash
npm install
npm run dev
```

## Deploying to GitHub Pages

1. Push this repository to GitHub (branch `main`).
2. In the repo, open **Settings → Pages** and set **Source** to **GitHub Actions**.
3. Every push to `main` builds and deploys automatically via `.github/workflows/deploy.yml`.

The site uses a relative base path, so it works at `https://<user>.github.io/<repo>/` as well as on a custom domain.
